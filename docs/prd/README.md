## Provenance

The workflow model, terminology and builder UX are mocked from Alex's public docs
(https://docs.alex.com/workflows/overview and its Rounds, Application Workflows, Triggers and
Actions, and Tracking pages), read 2026-10-01. Text is original; the product shape is borrowed.
Deliberate differences: no ATS sync, no job workflows in v1, LINE as a first-class channel in place of
phone calls, Thai-first.

## Conventions

- One PRD per feature area. Requirements are numbered (`FR-n`) so code, tickets and tests can cite them.
- If implementation scope changes, update the PRD in the same change.
